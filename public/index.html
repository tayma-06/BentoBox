04 · CREDITS & ABOUT

About this little box

BentoBox is a personal, hand-built fan corner — “the most random thing I built in the most random time.” Every card is a movie I love, presented in a bento layout with a webtoon-inspired aura: comic panels, halftone dots, speech bubbles, ink borders, and soft glowing light.

Movie information and artwork come from the TMDB API when a token is configured. Without one, the site runs on fallback data and original placeholder art.

  • Personal notes are editable — just change the personalNote field in data/movies.json.
  • Soundtrack mode plays each movie's original song on hover — full tracks via the Spotify Web Playback SDK when you connect a premium account, with official 30-second Apple Music previews as the guest fallback. Plus an optional background jazz track (real standards, streamed as official previews). Nothing is downloaded.
  • The interface and artwork system are original.

This product uses the TMDB API but is not endorsed or certified by TMDB.
